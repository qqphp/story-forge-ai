# 砚界 · StoryForge AI

把书籍信息自动转化为简介、多个版本的分享稿、自然化优化稿、微软语音配音、竖版封面和可预览视频。每本书对应一个独立工作流，多个工作流可以同时运行。

## 本地运行

需要 Node.js 22+、Python 3.11+ 和 FFmpeg。

```powershell
# 终端 1：前端
npm install
npm run dev

# 终端 2：后端
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.main:app --reload --port 8000
```

打开前端显示的本地地址。没有配置第三方密钥时，应用会以演示模式生成完整的文案、封面、音频和视频，方便验收整个流程。

## 外部服务配置

在页面右上角打开“接口与声音设置”：

- 大模型支持 OpenAI 兼容的 `/models` 和 `/chat/completions` 接口，可配置中转站地址、模型与密钥。
- 微软语音支持区域、密钥、输出格式和多个默认音色；音色列表通过微软接口查询。
- 分享稿会保留原稿，并单独生成经过 Humanizer-zh 原则优化的自然化版本。
- 分享稿与封面提示词在独立的“提示词库”集中维护，新建工作流时只需勾选模板。
- TeamoRouter 默认使用 `https://api.teamorouter.com/v1`，文案模型、图片模型均可在设置中调整。

也可以从 `.env.example` 复制环境变量进行配置。密钥不会进入源码；页面保存的设置仅存储在本机 `data/storyforge.db`。

## 抖音本地半自动发布

发布中心可以把已完成作品的视频、标题、作品简介、生成话题和多张封面整理成抖音发布任务。本地浏览器扩展会在用户已经登录的抖音创作页中选择视频、填写可识别话题，并把勾选的 3:4 与 4:3 封面分别上传到抖音竖封面和横封面位置，但不会读取或导出 Cookie，也不会点击最终发布按钮。

首次安装扩展：

1. 同时启动 StoryForge 前端与后端。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，选择“加载已解压的扩展程序”，加载项目中的 `browser-extension` 目录。
4. 打开 StoryForge 的“发布中心”，复制本地配对码。
5. 点击浏览器工具栏中的“砚界 · 抖音发布助手”，粘贴配对码并选择“保存并检测”。

发布流程：

1. 在发布中心选择一个已经生成视频的作品，确认抖音标题、作品简介和生成话题，并勾选需要上传的封面；抖音默认使用竖封面 3:4、横封面 4:3。
2. 创建发布任务，然后点击“打开抖音创作页”。
3. 如尚未登录，在真实抖音页面中扫码登录。
4. 点击页面右下角发布助手中的“上传并填充”。
5. 检查封面、可见范围、声明等平台设置，亲自点击抖音页面的发布按钮。
6. 发布成功后，在助手中点击“我已手动发布”，同步发布中心状态。

抖音创作页结构更新后，扩展可能无法识别输入框。此时任务会显示失败原因，可以手动填写或重新打开任务；扩展不会尝试绕过验证码或平台风控。
