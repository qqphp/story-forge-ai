# 砚界 · StoryForge AI

输入书名与作者，自动生成书籍简介、播讲稿、配音、字幕、封面和视频。支持批量制作，每本书独立管理。

## 本地启动

环境要求：Node.js 24.21.0、Python 3.11+、FFmpeg（加入 PATH）。

首次运行先安装依赖：

```powershell
npm ci
python -m pip install -r backend/requirements.txt
```

在两个终端中分别启动：

```powershell
# 终端 1：前端
npm run dev

# 终端 2：后端
python -m uvicorn backend.main:app --port 8000
```

打开 [http://localhost:3000](http://localhost:3000)。前端固定使用 3000 端口，并将 API 和媒体请求转发到后端 8000 端口，无需单独配置前端 API 地址。

## 使用与配置

在左侧导航完成设置，再回到“创作工作台”新建制作任务：

- **模型配置**：文本和图片服务分别填写 OpenAI 兼容的 API 地址与密钥，点击“获取模型”、选择模型后保存。修改地址或密钥后需重新获取模型。地址须保留 `/v1` 等路径前缀；图片服务也支持完整的 `/images/generations` 地址。在「Firecrawl 搜索」中可启用图书搜索并保存密钥，也可通过 `.env` 的 `FIRECRAWL_API_KEY` 配置密钥。
- **语音设置**：填写微软语音服务根地址与密钥，选择音色和输出格式。
- **提示词库**：查看《小琳爱读书的365天》的固定生成流程，调整节目模板的时长和表达偏好，并管理封面模板。新建任务时填写书名，作者、版本可帮助区分同名作品。
- **视频设置**：每份配音同时输出横版 16:9 和竖版 9:16，采用书封、旋转黑胶、音频频谱及播放进度布局，支持对应方向封面背景或 Pexels/Pixabay 自然风光背景。素材模式需配置对应服务的密钥。

也可参考 [.env.example](.env.example) 在项目根目录创建 `.env`。配置优先级为：页面已保存值 → 环境变量 → 默认值；页面保存的空密钥同样生效。密钥仅由后端读取。

未启动后端时可浏览演示界面；未配置相应服务时，文案、配音和封面使用演示内容。

## 制作说明

- 文案撰写会基于书籍研究结果完成节目策划、初稿、口语编辑与发音适配，再独立审核。审核未通过时定向返工一次。详情页可查看初稿和最终稿，也可以重新生成配音或视频。
- 书籍研究可使用 Firecrawl 查找公开资料，多套分享稿模板共用搜索结果。搜索不可用时使用模型有把握的资料，无法识别作品时在研究阶段报告原因。可在请求日志按「图书资料搜索」查看请求。
- 节目默认目标为 10～15 分钟，实际时长取决于音色、语速和停顿。Azure 使用 SSML 保留段落和语气，长稿会按语义分段合成，检测接近 10 分钟的分段并细分，最后合并音频并混入整期背景音乐。长稿的 MP3、Opus 类格式沿用语音设置，其他格式合成为 WAV。
- 字幕使用 stable-ts 对齐配音，首次运行需下载 Whisper 模型。字幕任务串行执行，排队和单次生成分别最多等待 15 分钟；超时会终止字幕进程并显示错误。
- 服务重启会将未完成任务标记为中断，并保留已保存的产物。详情页的“重试”会重新执行完整制作流程。
- 背景音乐可设置一条默认项，单条与批量制作会自动选中，也可手动更换或关闭。
- 勾选“本地生成封面”后，从十八套比例模板中生成方形、横版、竖版各一张，不调用图片模型。
- 已完成作品可以在封面页签重新生成选中的一张封面。已导出的视频保留原画面，重新生成视频时使用最新封面。
- 视频设置的“字幕烧录”页签可调整字体、颜色、背景、位置与边距，并预览真实烧录效果。
- 请求日志每页显示 12 条；“清空日志”会永久删除全部日志，包括当前筛选之外的记录。

## 本地数据

| 路径 | 内容 |
| --- | --- |
| `data/storyforge.db` | 设置、提示词与制作任务 |
| `data/media/` | 封面、配音、字幕与视频 |
| `data/voice_samples/` | 语音样本 |
| `data/` 下的缓存文件 | 音色翻译等缓存 |

备份时保留 `.env` 和完整 `data/` 目录；复制数据库前先停止后端。

## 常用命令

```powershell
npm run build  # 类型检查并构建到 dist/
npm run start  # 本地预览构建结果，仍需单独启动后端
npm run lint
npm test
python -m unittest discover backend/tests
```

字幕在配音对齐后清理句读标点，保留数字和英文词内符号。重新生成视频会复用现有时间信息同步更新 SRT、TXT、JSON，双版全部成功后再替换旧产物。

封面提示词必须包含 1:1、16:9、9:16。视频使用方形图作封套、对应方向图片作背景；旧作品重生成时自动补齐本地封面。视频设置支持上传唱片中心头像、恢复默认图片。字幕内置 16 款可选字体，来源、版本及 SHA-256 见 fonts/manifest.json，授权原文在 fonts/licenses/；重新获取字体可运行 python scripts/install_fonts.py。
